# SA-MP Super Roleplay (SRP2)

Spanish-language SA:MP roleplay gamemode. Originally by Andri1, maintained by Neetoons. Uses open.mp server (not vanilla SA-MP server).

## Build & Run

### Full Nix build (recommended)
```bash
nix build                          # builds everything
nix run                            # run server
```

### Compile gamemode only (dev shell)
```bash
nix develop                        # enters dev shell with pawncc + YSI
cd gamemodes
pawncc -Dgamemodes -i../pawno/include -i$YSI_INCLUDE -d3 -Z "-(+" "-;+" srp.pwn
```

### Compile filterscript
```bash
cd filterscripts
pawncc -Dfilterscripts -i../pawno/include -i$YSI_INCLUDE -Z "-(+" "-;+" maps.pwn
```

**No lint, typecheck, or test commands exist.** This is a Pawn codebase compiled with `pawncc`.

## Architecture

- **Server**: open.mp (openmultiplayer), built from source via Nix (`nix/open-mp.nix`)
- **Language**: Pawn (compiled to `.amx` bytecode by `pawncc`)
- **Database**: MariaDB/MySQL via `a_mysql` plugin (BlueG R41-4)
- **Compiler flake**: `github:neetoons/compiler-flake` provides `pawncc`

### Directory structure
```

  srp.pwn              # Main entrypoint (includes everything)
  core/                # All game logic
    administration/    # Admin commands by level
    anticheat/         # Anti-cheat system
    bank/              # Banking system
    color/             # Color definitions
    crew/              # Gang/crew system
    db/                # Database connection header
    dialog/            # Dialog system (showDialog, response)
    directives/        # Rules
    door/              # Doors
    furniture/         # Property furniture
    global/            # Global textdraws
    jobs/              # Job system (farmer, deliveryman, warehouse)
    key_areas/         # Key areas
    main/              # Core: callbacks.inc, functions.inc, commands.inc
    misc/              # Macros
    player/            # Player data, accounts, vehicles, weapons, GPS
    police/            # Police system
    properties/        # Properties, hospitals, fuel stations
    sub_modules/       # Subsystems: notifications, graffiti, taximeter, etc.
    vehicles/          # Vehicle system, tuning
    weapons/           # Weapons system
    world/             # World zones, enter/exit points
filterscripts/
  maps.pwn             # Map objects filterscript
pawno/include/         # Plugin includes (MySQL, sscanf, streamer, YSI, etc.)
scriptfiles/           # Runtime data (AC.txt, ECO.txt, callbackfix.amx)
db/
  srp_db.sql           # Database schema (6299 lines)
nix/                   # Nix build expressions
  plugins/             # Individual plugin derivations
  module.nix           # NixOS service module
```

## NixOS Deployment

### As NixOS module
```nix
# In your NixOS configuration
imports = [ (builtins.getFlake "github:neetoons/samp-super-roleplay").nixosModules.default ];

services.samp-server = {
  enable = true;
  # package is optional (uses built-in default)
  hostname = "My RP Server";
  port = 7777;
  database.enable = true;
};
```

## Key Details

- **Pawn compiler flags**: `-(+` (strip symbols), `-;+` (allow semicolons), `-d3` (debug)
- **YSI includes**: Fetched nightly from `pawn-lang/YSI-Includes` (assert() calls patched for 64-bit open.mp)
- **`MAX_PLAYERS`**: Redefined to 500 in `srp.pwn`
- **Database config**: `srp_db.ini` (hostname, username, database, password)
- **Encoding**: Pawn files use UTF-8 encoding
- **Open.mp components**: streamer, mapandreas, pawncmd, pawnraknet (built as open.mp components, not legacy plugins)
- **Legacy plugins**: Only `sscanf` and `mysql` (loaded via `pawn.legacy_plugins` in config.json)

## Gotchas

- **No `server.cfg`**: open.mp uses `config.json` (generated by Nix)
- **Plugin loading**: Legacy plugins (sscanf, mysql) in `plugins/`; open.mp components (streamer, etc.) in `components/`
- **PawnPlus removed**: All PawnPlus calls replaced with plain Pawn arrays
- **crashdetect removed**: Not used
- **Pawn.Regex removed**: Not used
- **`*.txt` in .gitignore**: Except `scriptfiles/SERVER/AC.txt` and `ECO.txt`
- **`plugins/` directory in .gitignore**: Built plugins are not committed
- **YSI patches**: All `assert()` calls commented out in YSI includes for open.mp compatibility
